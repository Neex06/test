АКАДЕМИЧЕСКИЙ КУРС — ПОДКЛЮЧЕНИЕ ЗАЯВОК К TELEGRAM

В архиве:
- index.html — страница сайта
- styles.css — стили
- script.js — форма отправляет данные обработчику
- worker.js — защищённый обработчик Cloudflare Worker, который отправляет сообщение Telegram
- README.txt — инструкция

ВАЖНО
Токен Telegram-бота нельзя вставлять в script.js или публиковать в коде сайта.
Токен хранится только в Cloudflare Worker как Secret.
Сайт, открытый двойным щелчком как file://, не является полноценным публичным сайтом. Для реальной работы его нужно опубликовать, например на Cloudflare Pages.

ШАГ 1. Создайте Telegram-бота
1. Откройте Telegram и найдите официальный аккаунт @BotFather.
2. Отправьте /newbot.
3. Укажите имя и username для бота (username должен заканчиваться на bot).
4. Скопируйте выданный Bot Token. Не отправляйте его никому и не вставляйте в HTML/JS.
5. Откройте нового бота по ссылке, которую дал BotFather, и нажмите Start.

ШАГ 2. Узнайте свой Telegram Chat ID
1. В Telegram найдите @userinfobot и нажмите Start.
2. Он покажет ваш числовой user ID — это ваш личный chat ID для отправки заявок.
3. Сохраните его. Не путайте его с токеном бота.
Для приёма заявок в группу сначала добавьте своего бота в группу и настройте отправку в групповой chat ID; для первого запуска проще использовать личный чат.

ШАГ 3. Создайте Cloudflare Worker
1. Войдите в https://dash.cloudflare.com/ (создайте аккаунт, если нужно).
2. Откройте Workers & Pages → Create → Worker (названия кнопок могут немного отличаться).
3. Создайте Worker, например academic-course-forms.
4. Откройте редактор кода Worker, замените стартовый код содержимым файла worker.js и нажмите Deploy.

ШАГ 4. Добавьте секреты в Worker
1. Откройте Worker → Settings → Variables and Secrets.
2. Добавьте Secret с именем TELEGRAM_BOT_TOKEN и значением токена от BotFather.
3. Добавьте Secret с именем TELEGRAM_CHAT_ID и значением вашего числового chat ID.
4. Добавьте переменную ALLOWED_ORIGIN со значением origin опубликованного сайта, например https://ваш-сайт.pages.dev (без завершающего /).
   - Если сайт ещё не опубликован, этот адрес можно добавить после шага 5.
   - Для первого быстрого теста можно временно задать ALLOWED_ORIGIN как *; перед публикацией обязательно замените на точный адрес сайта.
5. Сохраните изменения и выполните Deploy/Save and deploy.

ШАГ 5. Опубликуйте сайт
Самый прямой путь — Cloudflare Pages:
1. Создайте проект Pages и загрузите папку с index.html, styles.css и script.js (не нужно загружать worker.js как часть публичного сайта).
2. После публикации получите адрес вида https://имя-проекта.pages.dev.
3. В настройках Worker задайте ALLOWED_ORIGIN точно этому адресу и выполните Deploy.
Можно использовать любой другой статический хостинг; тогда укажите его HTTPS-origin.

ШАГ 6. Вставьте URL Worker в script.js
1. Скопируйте публичный URL Worker из Cloudflare, например https://academic-course-forms.<ваш-субдомен>.workers.dev.
2. Откройте script.js.
3. Найдите строку:
   const TELEGRAM_FORM_ENDPOINT = "ВСТАВЬТЕ_URL_CLOUDFLARE_WORKER";
4. Вставьте вместо текста реальный URL Worker, сохранив кавычки. Не вставляйте токен бота в эту строку.
5. Повторно загрузите обновлённый script.js на хостинг сайта.

ШАГ 7. Проверьте
1. Откройте опубликованный сайт.
2. Заполните форму тестовыми данными и нажмите «Подготовить заявку».
3. В вашем Telegram должен появиться текст «Новая заявка — Академический курс».
4. Если сообщение не приходит, проверьте: нажали ли Start у бота, правильны ли оба Secret, указан ли точный ALLOWED_ORIGIN и URL Worker в script.js.

ПРИМЕЧАНИЯ ПО БЕЗОПАСНОСТИ
- Не отправляйте токен бота в чат и не публикуйте его в GitHub.
- Не добавляйте токен в index.html, styles.css или script.js.
- Ограничение ALLOWED_ORIGIN уменьшает возможность вызова Worker с чужих сайтов, но само по себе не защищает от всех автоматических спам-заявок. Для публичного запуска полезно добавить Turnstile или rate limiting.
- Форма передаёт контактные данные. Укажите на сайте понятное уведомление о том, как эти данные используются.
- Бесплатные лимиты и интерфейс Cloudflare могут меняться.
